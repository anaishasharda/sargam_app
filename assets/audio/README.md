# Audio Files Required

To make the audio functionality work, you need to add the following audio files to this directory:

## Beginner Ragas
- `yaman_aaroh.mp3` - Raag Yaman ascending scale
- `yaman_avroh.mp3` - Raag Yaman descending scale  
- `yaman_swarmalika.mp3` - Raag Yaman melody with lyrics
- `bhoopali_aaroh.mp3` - Raag Bhoopali ascending scale
- `bhoopali_avroh.mp3` - Raag Bhoopali descending scale
- `bhoopali_swarmalika.mp3` - Raag Bhoopali melody with lyrics

## Intermediate Ragas
- `bhairav_aaroh.mp3` - Raag Bhairav ascending scale
- `bhairav_avroh.mp3` - Raag Bhairav descending scale
- `bhairav_swarmalika.mp3` - Raag Bhairav melody with lyrics
- `des_aaroh.mp3` - Raag Des ascending scale
- `des_avroh.mp3` - Raag Des descending scale
- `des_swarmalika.mp3` - Raag Des melody with lyrics

## Advanced Ragas
- `bhairavi_aaroh.mp3` - Raag Bhairavi ascending scale
- `bhairavi_avroh.mp3` - Raag Bhairavi descending scale
- `bhairavi_swarmalika.mp3` - Raag Bhairavi melody with lyrics
- `durga_aaroh.mp3` - Raag Durga ascending scale
- `durga_avroh.mp3` - Raag Durga descending scale
- `durga_swarmalika.mp3` - Raag Durga melody with lyrics

## Audio Requirements
- Format: MP3
- Quality: 128kbps or higher
- Duration: 30-60 seconds for each scale/melody
- Sample Rate: 44.1kHz
- Clear, professional recordings of each raga's scales and melodies

## For Testing
You can use any MP3 files temporarily for testing the audio playback functionality. The app will work with any audio files as long as they are named correctly and placed in this directory.

## Note
The audio comparison and analysis features are currently simulated. For real audio analysis, you would need to implement:
1. Pitch detection algorithms
2. Tempo analysis
3. Note-by-note comparison
4. Audio similarity matching
